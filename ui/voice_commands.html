🎤
Click microphone to start listening
Your voice command will appear here...

Available Commands

"go back" / "back" Navigate to previous page
"go forward" / "forward" Navigate to next page
"refresh" / "reload" Refresh current page
"search for [query]" Search the web
"new tab" Open new tab
"close tab" Close current tab
"next tab" / "previous tab" Switch tabs
"bookmark this" Bookmark current page
"scroll down" / "scroll up" Scroll the page
"go home" Navigate to homepage
